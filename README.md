# Shotgun-NF

## Introduction

Shotgun-NF is a Nextflow DSL2 pipeline for comprehensive shotgun metagenomics analysis.

The pipeline integrates read quality control, taxonomic profiling, metagenome assembly, genome binning, MAG quality assessment, functional annotation, antimicrobial resistance detection, biosynthetic gene cluster prediction, strain-level profiling and comparative genomics into a single reproducible workflow.

The pipeline is portable across HPC systems and local workstations through Conda and Apptainer environments.

## Database setup and reproducibility

Shotgun-NF requires several external reference databases that are not distributed with the repository. The exact database releases used during development, validation, benchmarking, and manuscript generation are documented in:

```text
databases/reference_databases_used_in_manuscript.tsv
```

A helper script is provided to prepare the expected database directory structure and generate a template configuration file:

```bash
bash scripts/download_reference_assets.sh databases
```

Users should then follow the generated instructions and update the resulting configuration file with the local paths to the downloaded databases. Newer database releases may be used, but results may differ from those reported in the manuscript. Full database installation guidance is provided in `DATABASES.md`.

## Pipeline summary

Shotgun-NF provides the following analysis modules:

- Read quality control (fastp)
- Host removal
- Taxonomic profiling (Kraken2 + Bracken + Krona)
- Functional profiling (HUMAnN3)
- Metagenome assembly (MEGAHIT)
- Genome binning (MetaBAT2)
- MAG quality assessment (CheckM2)
- MAG filtering
- Genome annotation (Prokka)
- Antimicrobial resistance prediction (RGI/CARD)
- Biosynthetic gene cluster prediction (antiSMASH)
- MAG taxonomic classification (GTDB-Tk)
- Whole-genome similarity analysis (FastANI)
- Strain-level phylogeny (MetaPhlAn + StrainPhlAn)
- MultiQC reporting
- Automatic HTML report generation (optional)

| Module                                         | Default        | Notes |
| ---------------------------------------------- | -------------- | ----- |
| fastp                                          | Yes            | Core preprocessing step |
| Host removal                                   | User-dependent | Controlled by `skip_host_removal` and `host_index` |
| Kraken2 / Bracken / Krona                      | Yes            | Kraken2 and Bracken are part of the main taxonomic branch; Krona can be skipped |
| HUMAnN                                         | Yes            | Controlled by `run_humann` |
| MEGAHIT assembly                               | Yes            | Core assembly step |
| MetaBAT2 binning                               | Yes            | Core MAG recovery step |
| CheckM2 quality assessment                     | Yes            | Core MAG quality assessment step |
| Prokka annotation                              | Yes            | Performed on retained MAGs |
| RGI antimicrobial resistance detection         | Yes            | Requires CARD database |
| antiSMASH biosynthetic gene cluster prediction | Yes            | Controlled by `run_antismash` |
| GTDB-Tk taxonomic classification               | No             | Controlled by `run_gtdbtk` |
| FastANI comparative genomics                   | No             | Controlled by `run_fastani` |
| StrainPhlAn strain-level phylogeny             | Yes            | Controlled by `run_strainphlan` |
| eggNOG-mapper functional annotation            | No             | Controlled by `run_eggnog` |
| MultiQC summary report                         | Yes            | Generated by default |
| Automatic HTML report generation                          | No             | Controlled by `make_report` |

## Typical usage

Run the complete workflow with full provenance reporting:

```bash
nextflow run . \
  -profile local \
  -c my.config \
  --input samplesheet.csv \
  --outdir results \
  --make_report true \
  -resume \
  -with-report results/pipeline_info/execution_report.html \
  -with-trace results/pipeline_info/trace.tsv \
  -with-timeline results/pipeline_info/timeline.html \
  -with-dag results/pipeline_info/dag.html
```

## Outputs
